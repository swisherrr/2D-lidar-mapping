# PlotScan.py Tutorial

## Overview
`PlotScan.py` is a visualization tool that creates polar plots from LiDAR scan data captured by `DataCapture.py`. It reads the CSV file containing scan data and generates an interactive polar plot showing the 360-degree environmental scan from the LiDAR sensor's perspective.

## Prerequisites

### Hardware
- None required (visualization only)

### Software
- Python 3.7 or higher
- CSV file generated by `DataCapture.py`

### Required Dependencies
- `matplotlib>=3.5.0` - Plotting library
- `numpy>=1.21.0` - Numerical operations

## Installation

1. **Ensure you're in the project directory**:
   ```bash
   cd <your-repo-directory>
   ```

2. **Install required dependencies**:
   ```bash
   pip install matplotlib numpy
   ```
   
   Or install from requirements.txt:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

### Basic Command
```bash
python PlotScan.py scans.csv --scan 0
```

### Command-Line Arguments

| Argument | Type | Default | Description |
|----------|------|---------|-------------|
| `csv_path` | Path | *required* | Path to the scans CSV file |
| `--scan` | int | `0` | Scan index to visualize (0-indexed) |
| `--units` | str | `mm` | Display units: `mm` (millimeters) or `m` (meters) |

### Examples

**Visualize the first scan (default)**:
```bash
python PlotScan.py scans.csv
```

**Visualize a specific scan by index**:
```bash
python PlotScan.py scans.csv --scan 2
```

**Display in meters instead of millimeters**:
```bash
python PlotScan.py scans.csv --scan 0 --units m
```

**Use a CSV from a different location**:
```bash
python PlotScan.py data/room_scan.csv --scan 0
```

## Understanding the Plot

### Polar Plot Layout
The visualization uses a **polar coordinate system** where:
- **Origin (center)**: Location of the LiDAR sensor
- **Angles**: Measured counter-clockwise from 0° (right side)
  - 0° = East
  - 90° = North
  - 180° = West
  - 270° = South
- **Radius**: Distance from the sensor to detected objects

### Plot Features
- **Blue dots**: Individual LiDAR measurements
- **Concentric circles**: Distance markers (e.g., 1000mm, 2000mm, etc.)
- **Radial lines**: Angular reference markers (every 45°)
- **Title**: Shows scan index (e.g., "LiDAR Scan #0")

### Example Interpretation
In the sample plot shown:
- Objects detected around 180° (left side) at ~800-1000mm distance
- Objects detected around 225-270° (bottom-left) at similar distances
- Sparse detections at 0° (right side) at ~2000mm
- Clear areas indicate no obstacles or surfaces outside LiDAR range

## Input File Requirements

PlotScan.py expects a CSV file with the following columns:

| Column | Description | Required |
|--------|-------------|----------|
| `scan_idx` | Scan number | ✓ |
| `angle_deg` | Angle in degrees | ✓ |
| `distance_mm` | Distance in millimeters | ✓ |
| `quality` | Signal quality (0-15) | ✓ |
| `x_mm` | Cartesian X coordinate | ✓ |
| `y_mm` | Cartesian Y coordinate | ✓ |

The script will validate these columns on load and throw an error if any are missing.

## Troubleshooting

### File Not Found Error
**Error**: `FileNotFoundError: CSV file not found: scans.csv`

**Solutions**:
- Verify the CSV file exists in the current directory
- Check the file path and name
- Use absolute path if needed: `python PlotScan.py C:\path\to\scans.csv`

### Missing Columns Error
**Error**: `ValueError: CSV file is missing required columns: x_mm, y_mm`

**Solutions**:
- Ensure the CSV was generated by DataCapture.py
- Don't modify column names in the CSV file
- Regenerate the CSV if it's corrupted

### No Points Found
**Error**: `ValueError: No points found for scan_idx=5`

**Solutions**:
- Check which scans are available in your CSV
- Scan indices are 0-based (first scan is `--scan 0`)
- Open the CSV file to see how many scans it contains
- Use a valid scan index: `--scan 0`, `--scan 1`, etc.

### Invalid Numeric Value
**Error**: `ValueError: Invalid numeric value in row`

**Solutions**:
- CSV file may be corrupted
- Regenerate the scan data with DataCapture.py
- Check for non-numeric values in distance/coordinate columns

### Plot Window Doesn't Appear
**Issue**: Script runs but no window opens

**Solutions**:
- Check if matplotlib backend is configured correctly
- Try setting backend explicitly:
  ```python
  import matplotlib
  matplotlib.use('TkAgg')  # or 'Qt5Agg'
  ```
- Ensure you're not running in a headless environment

## Technical Details

### Coordinate System Conversion
The script converts Cartesian coordinates (x, y) back to polar coordinates for plotting:

```python
angle = arctan2(y, x)    # Angle from +x axis
radius = distance        # Radial distance
```

### Unit Conversion
When using `--units m`, all values are divided by 1000:
- 1000mm → 1.0m
- 5432mm → 5.432m

### Data Filtering
The script filters data by `scan_idx` to display only the requested scan, allowing multiple scans to coexist in the same CSV file.
